How do I add an employer board?

Run the importer in a terminal with the same database path used to start this server. Replace the site slug with an employer's public Lever board.

python3 -m apps.api.import_opportunities --db YOUR_DB_PATH --site leverdemo

No automatic applications are sent. The complete setup is in the repository README.

THE REFERENCE BOUNDARY

A clear demo should make its limits clear, too.

The router is a typed heuristic, the swarm is a replay, and evidence digests are operator-declared. There is no hosted model, autonomous employment decision, payment, authenticated reviewer, or real customer outcome in this reference.
